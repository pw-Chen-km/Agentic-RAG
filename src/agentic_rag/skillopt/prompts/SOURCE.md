# SkillOpt v0.2.0 prompt bundle

The Markdown prompts in this directory are copied verbatim from Microsoft
SkillOpt tag `v0.2.0`, commit `e4ea6a6771e797ef820cdd8bfea64c57e0481065`:

https://github.com/microsoft/SkillOpt/tree/v0.2.0/skillopt/prompts

SkillOpt is MIT licensed. The PyPI `skillopt==0.2.0` wheel contains the prompt
loader but omits these Markdown package-data files. Agentic RAG temporarily
points that loader at this pinned bundle while the native trainer is running.
