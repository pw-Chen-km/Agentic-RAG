These inputs compare actual paths for the same TRAIN question under historical
Skills A and B. Read the recorded rule differences, then check which decisions
actually changed and what happened afterward. The two paths may reach different
information states, so the same decision number does not guarantee the same
available evidence. Use references such as A1 and B2.

A change in wording or final score alone is not proof of changed retrieval.
Record benefits, regressions and unchanged behavior. Several edited rules and
model variation can contribute to a difference; do not claim one action's
effect was isolated. Historical Skills explain the evidence. The Current Skill
is the only future edit target, and it may already address a historical problem.
