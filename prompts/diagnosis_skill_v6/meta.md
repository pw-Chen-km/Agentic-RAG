These records compare two actual runs of each training question. Run A used
an earlier Skill; run B used a proposed change to that Skill. You receive the
complete earlier Skill A and the exact rule changes that produce Skill B.
Both runs were executed, including proposals that were later rejected. A and
B are examples to study. The Current Skill is the set of instructions that
may be improved now; it can differ from both earlier versions.

Describe what information each run had, what each agent did, and how their
results differed. Explain the part of the earlier instructions that might
relate to the difference when the record supports that connection. If the
same actions continued despite different wording, say so. Record useful
choices, unnecessary work, and worse results as appropriate.

Run A and run B can acquire different information. The same turn number does
not mean that both agents knew the same things. Shared passage text is shown
once to save space, but it belongs to a run only when that run's results
actually delivered it. Keep the two runs' knowledge separate.

A better final score or a rule wording change alone does not prove why a run
improved. Several rule changes, different search results, or variation in the
model's answers may explain it. Base the finding on what actually happened.
Do not assume that restoring an earlier rule will help the Current Skill.
